# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a native Next.js 404 page that explains a route may be missing or coming soon and gives visitors clear recovery actions.

**Architecture:** Create the App Router convention file `app/not-found.tsx`. It renders inside the existing root layout, so the shared navbar and footer stay intact; its content uses only established portal utility classes and Next.js `Link`.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS utility classes already defined in the project.

## Global Constraints

- Preserve the existing 34cats warm-neutral visual system and literal product voice.
- Do not add dependencies or new decorative assets.
- Keep the page responsive and keyboard accessible.
- Primary recovery action must link to `/#apps`; secondary action must link to `/`.

---

### Task 1: Add the native 404 surface

**Files:**
- Create: `app/not-found.tsx`

**Interfaces:**
- Consumes: Next.js App Router's `not-found.tsx` convention and existing portal CSS utility classes.
- Produces: A default React component rendered for unknown routes with a 404 label, explanatory heading/body copy, and two recovery links.

- [ ] **Step 1: Implement the page component**

```tsx
import Link from "next/link";

export default function NotFound() {
  return (
    <main className="flex min-h-[calc(100vh-4rem)] items-center px-5 py-20 md:px-8">
      <div className="mx-auto w-full max-w-2xl text-center">
        <p className="portal-label text-signal">404</p>
        <h1 className="portal-heading mt-4 text-4xl sm:text-5xl">
          This page isn’t available yet.
        </h1>
        <p className="mx-auto mt-6 max-w-xl text-base leading-relaxed text-copy-muted sm:text-lg">
          The page you requested either doesn’t exist, or it’s coming soon but isn’t available yet.
        </p>
        <div className="mt-8 flex flex-col items-center justify-center gap-3 sm:flex-row">
          <Link href="/#apps" className="portal-button portal-button-primary w-full sm:w-auto">
            Browse apps
          </Link>
          <Link href="/" className="portal-button portal-button-secondary w-full sm:w-auto">
            Back home
          </Link>
        </div>
      </div>
    </main>
  );
}
```
